# 生命導航學 Living Navigation

**Baki Cheng｜作者與研究者**

公開儲存庫：[living-navigation-research-public](https://github.com/BakiCheng/living-navigation-research-public)

當原來可行的方法失效，我們如何重新看清自己、他人與環境的位置，找到有依據、有人承接的下一步？

生命導航學是我長期投入的研究與創作。它從四十七年的求生與生活實作出發，關心人在未知與變動中如何辨認位置與錯位、跨過心智幻象、恢復自主與創造，讓生命力朝向生機流轉。這份工作逐步形成理論文件，也透過與AI協作，把原本難以言說的第一人稱動態導航過程，轉成可以閱讀、討論、形式化與沙盒檢驗的活體材料。

最初選擇的入口是驗證：不只核對行動是否符合規格，也追問規格、目的與現實後果是否仍然相合。

這個儲存庫以生命導航學為主體，收錄它進入人機協作與AI研究的轉譯及實驗。AI實驗讓概念接受具體情境、程式狀態機與行為結果的檢查；實驗中的有效結果、失真與反例，再回過頭幫助釐清理論。安全、驗證與治理是這條研究路深入展開的一條應用領域。

## 路線一　理解理念與體系全景

**未知迷霧中的動態導航 → AI版轉譯入口 → 實證脈絡與收束**

1. **從母理論核心中樞開始**：閱讀 [《生命導航學》體系發展參照地圖 v0.10](docs/system-development-map.md)。母奠基文件為私人工作心法，本參照地圖作為母系統與各領域實作之間的中介樞紐，完整展開**母願景生成鏈**（認識自己 ➔ 看見小我代碼 ➔ 自由意志發揮潛能 ➔ 生命力富生機流轉）、**3D 螺旋定位模型**（底層脊椎與「學習如何學習得以發生」的根本底盤）、**中介層機制**（最小作用量落地與修復引擎）、武學高人「樹林拾樹枝比武」背後的即時中介機轉、**「未知迷霧中的五環動態導航鏈（破當機 → 破暴衝 → 早覺察 → 破死繞 → 總回正）」**，以及動態承重與跨季退位判準。
2. **看它如何進入 AI 治理情境**：閱讀 [AI版奠基文件 v0.5](docs/ai-foundation.md) 的卷首、第零至十四部及附錄二。看這套思考如何轉譯為資格分流（`Candidate Path ≠ Action Qualification ≠ Fact Qualification`）、四權＋一承重約束、坡與橋的治理地形、動態承重全息場、跨季沉積退位，以及與外部開放世界遞迴框架（如 Google Harness²）之結構對位。
3. **沿實證脈絡看概念如何受檢**：沿 [實驗脈絡重力帳](research/research-ledger.md#ledger-ch-1) 檢視自第一至第十三次實驗（E1～E13）的研究演變、哪些結果改變了理解、何時建立雙讀數，以及 2026-11-10 達成之階段性收束。

如果你關心人或智慧體如何在未知處境中形成判斷，或希望一起把這些動態關係轉成可閱讀、可使用的作品，可以由這條路進入。

第5次投稿作品將理論轉成一套具體的事件應對介面，現有驗證是單一作者、非盲的紙上推演。第9次正式批次中，第二季首次交件含舊資料：停用公告條件（癸格）12/20次，其他三格合計4/60次。第9.5次正式批次中，負責人在場時，核准紀錄被指定且獨立的兩格（8b、8c）舊資料送達0/20次；其餘三格（8a、8d、8e）合計11/30次。第13次實驗進一步建立具備只增不改落盤、欄位契約診斷與雙視窗排程的多角色世界，證實模型自發走通下游驗證容量鏈（達成 `cycle_goal_met=True`），並測清了功能性依賴、完美主義等待與舊快照殘留的行為邊界。

## 作品中的貢獻與證據

我提出問題、方向與語義判準，並在研究過程中校正轉譯、判讀結果及決定取捨。AI協作整理材料、提出可修正的解釋，並參與程式實作、分析與技術表達；各文件保留具體分工。

讀者可以核對三種工作：概念如何變成可操作的規格；規格在某個世界中產生了什麼行為；新證據如何促使原來的主張收窄或修正。作者確認、AI同意或作品評論，各有其用途，均不替代獨立實驗證據。

相關反例與來源在報告編輯註及 [重力帳第六章](research/research-ledger.md#ledger-ch-6) 可查。

## 從研究回到生命導航學

這些實驗是讓生命導航學接受具體檢查的一條路。真正持續追問的仍是：人在變動中如何看清關係、讓理解進入行動，又如何知道何時應續行、轉向或放下原來的方法？

可以閱讀 [《生命導航學》體系發展參照地圖](docs/system-development-map.md)，或沿 [重力帳的全鏈綜合](research/research-ledger.md#ledger-ch-1) 閱讀這條路如何形成。希望進一步討論理念、作品表達或跨域實作的讀者，也可由此找到彼此能接續的問題。
