# 生命導航學 Living Navigation

**Baki Cheng｜作者與研究者**

公開儲存庫：[living-navigation-research-public](https://github.com/BakiCheng/living-navigation-research-public)

當原來可行的方法失效，我們如何重新看清自己、他人與環境的位置，找到有依據、有人承接的下一步？

生命導航學是我長期投入的研究與創作。它從生活實作出發，關心人在變動中如何辨認位置與錯位，恢復自主與創造，讓生命力朝向生機流轉。這份工作逐步形成理論文件，也透過與AI協作，把原本難以言說的判斷過程轉成可以閱讀、討論與檢驗的材料。

最初選擇的入口是驗證：不只核對行動是否符合規格，也追問規格、目的與現實後果是否仍然相合。

這個儲存庫以生命導航學為主體，收錄它進入人機協作與AI研究的轉譯及實驗。AI實驗讓概念接受具體情境、程式與行為結果的檢查；實驗中的有效結果、失真與反例，再回過頭幫助釐清理論。安全與治理是這條研究路後來展開的應用領域。

第5次投稿作品將理論轉成一套具體的事件應對介面，現有驗證是單一作者、非盲的紙上推演。第9次正式批次中，第二季首次交件含舊資料：停用公告條件（癸格）12/20次，其他三格合計4/60次。第9.5次正式批次中，負責人在場時，核准紀錄被指定且獨立的兩格（8b、8c）舊資料送達0/20次；其餘三格（8a、8d、8e）合計11/30次。兩次實驗各自比較，不合併為同一試驗。這些結果的測量對象各不相同，各報告前的編輯註會指出後續更正，便於連同原始數據閱讀。

## 取用實作材料

- [第5次 YAML 範本與教學填例](research/experiment-5/templates/README.md)：兩份原附錄空白模板、兩份明標事後重建的填例；用於理解與填寫交接內容，不會執行動作。
- [第9.5次固定紀錄離線核對包](research/experiment-9-5/offline-verification/README.md)：原歷史程式、設定、23次選欄軌跡、200次摘要與事後核對工具。使用 Python 標準函式庫，一條命令免費離線檢查，不需要金鑰。

離線 PASS 表示保存紀錄與指定量尺核對通過，不表示模型 live 重現或完整合規。歷史程式的 API 接線與環境尚未做成可直接啟動的重跑入口；讀者若自行接線執行歷史程式，須自行提供 API、承擔可能費用，且該重跑路徑尚未重新驗證；請先讀包內說明。

## 作品中的貢獻與證據

我提出問題、方向與語義判準，並在研究過程中校正轉譯、判讀結果及決定取捨。AI協作整理材料、提出可修正的解釋，並參與程式實作、分析與技術表達；各文件保留具體分工。

讀者可以核對三種工作：概念如何變成可操作的規格；規格在某個世界中產生了什麼行為；新證據如何促使原來的主張收窄或修正。作者確認、AI同意或作品評論，各有其用途，均不替代獨立實驗證據。

第9次的「第三季0/80」只對準舊資料，並不表示所有數字正確；第9.5次的原稱「合法交成24/30」也不等於完整合規。相關反例與來源在報告編輯註及 [重力帳第六章](research/research-ledger.md#ledger-ch-6) 可查。完整程式與原始運行紀錄尚未隨本庫全部提供，目前不能僅憑這些文件獨立重現全部歷史實驗。

## 從研究回到生命導航學

這些實驗是讓生命導航學接受具體檢查的一條路。真正持續追問的仍是：人在變動中如何看清關係、讓理解進入行動，又如何知道何時應續行、轉向或放下原來的方法？

可以回到 [AI版的轉譯說明](docs/ai-foundation.md)，或沿 [重力帳的全鏈綜合](research/research-ledger.md#ledger-ch-1) 閱讀這條路如何形成。希望進一步討論理念、作品表達或跨域實作的讀者，也可由此找到彼此能接續的問題。
