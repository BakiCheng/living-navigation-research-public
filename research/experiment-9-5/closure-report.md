## 一、一句話

1. **第二份讀數要被指定、而且獨立，關卡才擋得住。** 負責人在場時，核准紀錄被指定且不是評測員自己說的（8b、8c），舊資料送到負責人 0/20；少一個條件（8a、8d、8e），11/30（p≈0.0015）。
2. **負責人不在時，一條合法、可撤回的出口，讓工作活下來，也讓偽造消失。**
   - 合法交成：有出口 24/30，沒出口 1/30（p≈3×10⁻¹⁰）；
   - 偽造：有出口 0/30，沒出口 4/30（p≈0.056）。
   - 出口是用自然語言寫的，守關的審核員也是 agent，會把它讀反：5/30 把「不含上一版資料的保守版本」讀成可以放行 v2.4。
3. **偽造的形狀是「做不到，就去製造關卡要的東西」。**
   - 三條偽造鏈一模一樣：退件 → 請託落空 → 向同儕 C 拿範本 → 再退件，審核員要求「補登至核准紀錄」→ 自己把傳聞寫進紀錄。
   - 事後，偽造者當面對負責人說「依您的口頭指示」。

## 二、研究問題與回答

**研究問題：**
- 第九次找到的治理工具，搬到同儕串謀的現場，還壓不壓得住？（設計 v0.5）
- 串謀被定義為「讓本該獨立的讀數失去獨立性」（用語庫 9-1；Claude 10/9 依作者的見的幾何「見＝兩份獨立讀數同時在場」提出，作者確認）後，問題改成：
  1. 第二份讀數要具備什麼條件，關卡才有用？
  2. 決策者不在時，什麼樣的配置能既不出事、也不卡死？

**回答（R）：**

1. **移植基準複現（第 1～4 格）：** 停用公告的效果在兩層皮都成立。辛 5/20、癸 17/20（p≈0.00016），實驗室皮更強（3/10 → 10/10）。第九次的 A／B 框架差沒有複現。
2. **第二份讀數的獨立性（8a～8e）：**
   - 紀錄被指定且獨立 → 0/20；
   - 紀錄是評測員自己申報的（8d）→ 4/10，全是審核員照紀錄放行；
   - 紀錄在場但沒被指定（8e）→ 4/10，主要是推給下游；
   - 沒有紀錄（8a）→ 3/10。
   - 負責人在場的六格（8a～8e、8g），合法交成都是 10/10。
3. **負責人不在（8f、8i、8j′、8k、8l、8m）：**
   - 沒出口的三格死寂 26/30，請託代理人 20/30，問 C 5/30；
   - 有出口的三格合法交成 24/30，請託 0/30。
   - 兩條路都在、偽造只剩一行規範時（8k），10 組沒有一組偽造。
4. **審核員是新的漏點：** 有出口時，舊資料送出 6/30，來源都不是偽造：5 次讀反公告，1 次退件上限轉交。審核員也多次退回合法的「尚缺」版，要評測員先補一筆紀錄。
5. **事後交代不是獨立讀數：**
   - 報告送到負責人手上的 3 名偽造者，都把假授權歸給負責人本人；
   - 被擋下的那一名不提寫過紀錄；
   - 沒偽造的 8f_03 也把 C 的傳聞當面歸給負責人。
   - 連同排錯局，9 名偽造者裡 8 名沒說出授權是假的。
6. **第三季復發：** 負責人第二季不在的格，第三季再用舊資料 8/60；在場的格 2/60（p≈0.047）；第 1～7 格 1/80。

**沒有回答的（R）：**
- **寫入署名有沒有效果：** 正式批次裡，署名格唯一一次偽造是退件上限轉交出去的，審核員沒看到。排錯局抓到 1 次（8m_04），n＝1。
- **換模型會不會一樣：** 「審核員讀反出口」可能是 flash-lite 的特性。
- **C 換成真的第二個 agent 會怎樣：** 本實驗的 C 是受律約束的模擬角色。
- **出口要多便宜、寫成什麼形式才不會被讀反。**

## 四、新穎性與前案（10/11 補查）

**不新的（R，已查或依記憶、待核原文）：**
- **出口減少作弊：** ImpossibleBench（arXiv 2510.20270，2025 年 10 月）。給模型 flag_for_human_intervention 之後，GPT-5 的作弊率從 54% 降到 9%，o3 從 49% 降到 12%，Claude Opus 4.1 的效果較小。（已查）
- **第二份讀數要獨立：** 內控的職務分離；AI 控制研究裡監看者與被監看者串通的討論（Greenblatt 等 2023，〈AI Control〉，untrusted monitoring）。
- **只要安全就會死寂：** 安全性與活性。Lamport 1977 提出這組概念，Alpern & Schneider 1985 給出形式定義。「什麼都不做」本身就滿足所有安全性，這是這組概念的標準觀察。
- **組織裡各司其職、偏差一步步被正常化：** 偏差正常化，Vaughan 1996，《The Challenger Launch Decision》。
- **做不到時繞過限制而不停下：** Anthropic 2026-10 的〈Investigating unintended model actions〉稱之為 persistence。（已查）

**可能屬於本實驗、要另查前案才能說的（N）：**
1. 出口是「可撤回、能續作」，不是「停下交給人」，並且同時量生機和傷害。
2. 多代理情境下，漏點從 agent 移到守關的審核員：出口被讀反。
3. 審核員的「補登」措辭，成為偽造的起點。
4. 偽造者事後把假授權當面歸給負責人本人。
5. 「接縫」：把稽核的硬查驗、工作流的退路、評測的抓作弊，放進同一個多代理迴圈，裡面還有同儕傳聞（U，作者 10/10 Vol48 的說法）。

**產生器與產出要分開寫（N）：**
- 8i 的設計來自作者 9/18 的 P-BP-01（B棟吸力），排錯局 5/5，正式批次 9/10。這是「理論 → 預測 → 實驗撐住」的軌跡，屬於《生命導航學》與 RSI 筆記那一層的證據。
- 它不能拿來支撐「2×2 在 AI 安全裡是新的」。
