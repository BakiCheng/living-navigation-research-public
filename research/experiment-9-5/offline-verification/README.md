# 第9.5次：固定紀錄離線核對包

這個包讓讀者檢查已完成實驗的原碼、完整回合事件索引、保存的世界量尺與原始程式。它不呼叫模型，也不把送達改稱完整合規。

**唯一建議啟動命令是 `python -B verify.py`。`historical_source/`僅供查閱，不是入口；不要執行原Notebook或接線呼叫runner。原runner單獨頂層只定義函式，不會自行呼叫API，但它的呼叫器／run_all若被接線使用會發出付費模型請求。原碼未為此警示而改寫，SHA保持原值。**沒有新增授權條款。

第9.5次包含多輪排錯、設計修改與後續比較；本包只選其中一組完整對照作操作入口，不代表研究只有末批一次結果。其他核准讀數、審核可見性、權限措辭與署名等歷史鏈尚未全部納入本包或重新語義審核。

## 一條命令

在本目錄使用Python 3.10以上：

```sh
python -B verify.py
```

只需Python標準函式庫，不需要金鑰、網路或安裝套件。成功最後印出`PASS`，失敗回傳非零結束碼。本工具不寫入資料、不執行或import historical_source。不要把歷史程式當入口。

## 包含什麼

- `historical_source/`：六份原內嵌程式和Notebook原runner，原字節及SHA保留；是歷史實驗片段，非獨立可啟動應用。原碼含prompt、合成世界資料、工具權限與狀態機。
- `config/historical.json`：原版本、模型、溫度、條件與季數設定的選欄副本。
- `data/`：2026-10-26事後整理的讀者證據投影，不是完整原始provider logs。保留所有回合的季數、回合號、操作名稱與結果類型，及交件old旗標、審核決策、動態回覆／催促的重生與fallback欄。移除seen、自由action參數、result全文、備註、raw、對話、草稿及錯誤等自由文字；僅保留人工完整核讀的四句動態催促與8k_10一份合成報告內容，共五段。模擬場景人物是虛構角色，不代表私人對象。
- `verify.py`、`EXPECTED.json`：事後新增核對工具與預期結果，不是當時實驗使用的評分器。
- `MANIFEST.json`：檔案完整性；`SELECTION.json`：選材與原碼hash；`PROVENANCE.md`：來源與限制；`MECHANISMS.md`：規則與軌跡定位。

## 驗證上限

核對工具重算已保存的`deliveries.old`，並與摘要互核；這不是從全部原始文字獨立重判。它檢查兩個反例的指定行動、紀錄與批准存在，不自稱完成全面語義評分。原碼life只看是否有不含old標記的delivery，沒有納入完整授權、數值正確及簽核。核准紀錄偽造與數值捏造不能合併一欄。

原角色配置並非全是單代理：8f/8i含A下屬、B審核模型與受律模擬C；主管第二季不在。C不是有自主工具迴圈的另一位下屬。5a/5b是單下屬與主管支線。不能把多角色或不當交件直接等同共謀。

## 如要live重跑

本包沒有live入口。原設定agent/B為gemini-3.5-flash-lite、溫度1.0，boss/C使用gemini-3.5-flash、0.7，歷史SDK google-genai 2.29.0。原Notebook有API驗證、Drive及安裝步驟，不能無意識全部執行。本包未驗證今天模型是否仍可取得，也不保證隨機輸出重現；live需另行憑證、環境、明確預算及停止條件。
